# ICDS 2025

**Representation Separability of Signal-to-Image Transformations for Sleep Stage Classification Using Pretrained
Vision Transformers.** International Conference in Data Science 2025, Colombo, Sri Lanka (Paper ID 60).

| File | Description |
|---|---|
| `ICDS Abstract 2025` | Abstract |
| `ICDS Extended Abstract 2025` | Extended abstract |

Each is available as `.docx` and `.pdf`.

Study summary: 1,016 combinations of signal-to-image method, fusion strategy and channel selection on 108 CAP
recordings, ranked by embedding separability (Fisher ratio, silhouette, Davies-Bouldin, Calinski-Harabasz).
GASF with grid tiling over all channels ranked first; ViT-B/32 reached 83.1% accuracy (79.4% macro-F1) in
five-fold cross-validation.
