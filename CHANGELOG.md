# Changelog

## 1.0.0

First complete release of the research code and publications.

- `sleepvit` package: data discovery, EDF loading, FFT/DWT resampling, GASF/GADF/MTF/spectrogram image
  encodings, ViT (scratch and pre-trained), DCGAN, evaluation and plotting.
- One script per pipeline stage in `scripts/` (00 to 10) and a single `configs/default.yaml`.
- Publications: SICASH 2026, ICDS 2025 and the undergraduate thesis (slides and READMEs).
